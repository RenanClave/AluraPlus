# Alura Plus 🎓

Projeto desenvolvido durante curso da [Alura](https://www.alura.com.br/), com o objetivo de praticar os fundamentos de **HTML** e **CSS** na construção de uma landing page.

---

## 📄 Sobre o projeto

O **Alura Plus** é uma página de apresentação de um serviço de assinatura, desenvolvida com foco na estruturação semântica em HTML e na estilização com CSS. O projeto simula uma landing page real, com seções de destaque, benefícios e call-to-action.

---

## 🚀 Tecnologias utilizadas

- **HTML5** — estruturação e semântica do conteúdo
- **CSS3** — estilização, layout e responsividade

---

## 📚 Conceitos praticados

- Estrutura semântica com HTML5 (`section`, `header`, `main`, `footer`)
- Flexbox para alinhamento e layout
- Variáveis CSS (`--custom-properties`)
- Responsividade com unidades relativas e `flex-wrap`
- Boas práticas de nomenclatura de classes (BEM)
- Organização de arquivos CSS
